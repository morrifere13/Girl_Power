🔧 DÉPANNAGE RAPIDE:

❌ Backend ne démarre pas
   → Vérifiez que MySQL/XAMPP est lancé
   → Vérifiez le fichier .env dans backend/
   → DB_HOST=localhost
   → DB_USER=root
   → DB_PASSWORD=votre_mot_de_passe
   → DB_NAME=girl_power_db

❌ Frontend affiche erreur
   → Vérifiez que le backend tourne (port 5000)
   → Ouvrez la console du navigateur (F12)
   → Relancez: Ctrl+C puis npm run dev

❌ Base de données non trouvée
   → Importez database.sql dans MySQL
   → mysql -u root -p < backend/database.sql
   → Ou utilisez phpMyAdmin (XAMPP)
