## 🚀 Démarrage Ultra-Rapide

### Si c'est votre première installation:

```bash
# 1. Installer les dépendances
Double-cliquez sur: install.bat

# 2. Configurer MySQL
- Lancez XAMPP ou MySQL
- Importez: backend/database.sql

# 3. Configurer .env
- Ouvrez: backend/.env
- Mettez votre mot de passe MySQL

# 4. Lancer l'application
Double-cliquez sur: start.bat

# 5. Ouvrir dans le navigateur
http://localhost:3000
```

### Si déjà installée:

```bash
# Option 1: Utiliser le script
Double-cliquez sur: start.bat

# Option 2: Manuellement
Terminal 1: cd backend && npm start
Terminal 2: cd frontend && npm run dev
```

## 💡 Conseils Pro

### 1. Première Utilisation
1. Lancez l'application
2. Explorez le **Tableau de bord**
3. Allez dans **Candidates** pour voir les données de test
4. Cliquez sur **Nouvelle Candidate** pour tester le formulaire
5. Naviguez entre les 6 sections du formulaire
6. Testez la **recherche** et les **filtres**
7. Basculez entre **vue Liste** et **vue Cartes**

### 2. Raccourcis Utiles
- **Réduire la sidebar** → Clic sur X en haut
- **Exporter rapidement** → Clic sur 📥 dans la sidebar
- **Imprimer une fiche** → Ctrl+P sur la page détails
- **Recherche rapide** → Focus automatique sur la barre

### 3. Meilleures Pratiques
- Remplissez **tous les champs** du formulaire (surtout les obligatoires *)
- Utilisez **Précédent/Suivant** pour naviguer entre sections
- Les **âges se calculent automatiquement** - ne les saisissez pas
- **Exportez régulièrement** vos données (backup)

## 🐛 Problèmes Fréquents

### ❌ "Cannot GET /"
→ Le backend n'est pas lancé
→ Lancez: `cd backend && npm start`

### ❌ "ECONNREFUSED"
→ MySQL n'est pas démarré
→ Lancez XAMPP ou MySQL

### ❌ "ER_ACCESS_DENIED_ERROR"
→ Mauvais mot de passe MySQL
→ Vérifiez backend/.env

### ❌ Page blanche
→ Erreur JavaScript
→ Ouvrez la console (F12) et regardez les erreurs
